    CareSync

    A full-stack healthcare platform with separate portals for patients and clinicians. Patients register and book appointments, and clinicians get a dashboard and calendar with patient vitals linked in. Access is controlled with JWT authentication, OAuth 2.0, and role-based permissions across four user roles. Patient data is scoped by clinic, and the API adds audit logging and rate limiting.

    allRunners

    A full-stack running tracker. Log runs with distance, time, and notes, then see pace, stats, goals, and splits. Record GPS trails in the browser and check local weather. A Flask REST API with 18+ endpoints powers a vanilla JavaScript app that syncs with Smashrun through OAuth 2.0, and it installs as a PWA with offline support.

    Diamond Price Prediction

    Compares five regression models that predict diamond prices from the 53,940-diamond ggplot2 dataset. The tuned Random Forest performed best, with a test R² of 0.983 and a mean absolute error of $266. SHAP analysis shows that carat and physical size dominate price.
