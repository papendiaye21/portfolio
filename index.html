  • MYCEL

    multi-agent system

    A multi-agent AI system built to explore how autonomous agents can persist what they learn, change code safely, and stay inside clear rules. It stores state in SQLite, uses embedding models for retrieval, rewrites Python through its AST, runs agent code in subprocess sandboxes, and applies governance patterns to control what agents may do.

  • Foreworth

    formerly Spend Sense

    A fintech app for Gen Z, started at a URI hackathon, that answers "Can I afford this?" before a purchase. It tracks buy now, pay later payments and pairs them with a retirement and future-value estimator, so a small purchase today shows what it could cost later. Claude generates the plain-language explanation.
